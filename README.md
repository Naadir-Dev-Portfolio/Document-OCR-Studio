# OCR-Spin-Extractor

Extracts exercise and spin session data from images using OCR pipeline

Built by [Naadir](https://github.com/Naadir-Dev-Portfolio)

## Overview

Automatically extract workout metrics from photos of fitness tracker screens, class performance displays, and Peloton/spin session captures. Uses optical character recognition to parse performance data and export to structured CSV format.

## Features

- Image-to-text OCR pipeline for fitness data
- Automatic metric extraction (distance, calories, duration, resistance)
- Session data aggregation and normalization
- CSV export for fitness tracking integration
- Support for multiple spin bike and tracker formats

## Tech Stack

Python · OCR · pandas · CSV

## Setup

```
pip install -r requirements.txt
python main.py
```
